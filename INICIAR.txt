=== NUEVO: DEMOSTRACION DE REMEDIACION (FASE 2) ===
IMPORTANTE: Los 250 casos publicos solo contienen logs y etiquetas, NO
repositorios listos para reparar. Esta demo usa proyectos pequenos EJECUTABLES,
creados dentro de results/*/workspaces. No toca repositorios personales.

1) Prueba de funcionamiento SIN IA (comprueba la logica de correccion):
   python -u remediation_demo.py --mode rule --scenario all --apply --out results/remediacion-reglas

2) Demo CON IA LOCAL GRATIS, cuando Ollama ya este funcionando:
   ollama list
   python -u remediation_demo.py --mode ollama --model qwen2.5-coder:3b --scenario both --apply --out results/remediacion-ollama

3) Ver un caso para exponer ante el profesor (fallo -> IA -> diff -> retest):
   python mostrar_remediacion.py --out results/remediacion-ollama --scenario unit
   python mostrar_remediacion.py --out results/remediacion-ollama --scenario lint

4) Resultados de remediacion:
   results/remediacion-ollama/summary.json
   results/remediacion-ollama/remediation_cases.csv
   results/remediacion-ollama/unit_detail.json
   results/remediacion-ollama/unit_patch.diff

La seleccion de herramienta es realizada por Qwen en modo ollama; la ejecucion
utiliza herramientas predeterminadas y seguras en un sandbox. "rule" NO usa IA.
La reparacion de pruebas unitarias extiende el alcance del paper original;
'lint_fix' es una herramienta inspirada en LogSage. No se replica el RAG privado
de ByteDance ni sus resultados industriales con estos ejemplos controlados.

Para previsualizar sin modificar siquiera el workspace de codigo:
   python remediation_demo.py --mode ollama --scenario unit --out results/preview
Omitir --apply impide ejecutar parches.
